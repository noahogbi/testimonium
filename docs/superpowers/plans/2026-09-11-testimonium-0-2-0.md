# testimonium 0.2.0 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Close the eighteen capabilities a real integration found missing, so this package can replace the tool it was extracted from without losing functionality.

**Architecture:** Six behaviour changes and four API-surface additions. The headline change - escalating the ladder before making an accusation - is triggered in `check()`, which already owns the verdict, while `nextAction` gains a flag and stays claim-blind. Three changes reverse doctrine the binding spec states positively, so each carries an amendment to that spec at every site the sentence appears.

**Tech Stack:** TypeScript (strict), Node >= 20, vitest, zero runtime dependencies, ESM.

**Spec:** `docs/superpowers/specs/2026-09-11-testimonium-0-2-0-design.md`, which amends `docs/superpowers/specs/2026-09-06-testimonium-design.md`. **Read both.** The 2026-09-06 spec is the binding authority for everything 0.2.0 does not name; where they disagree, the amendment table in 0.2.0 section 2 is the list of places 0.2.0 wins.

## Global Constraints

- **Node >= 20. Zero runtime dependencies.** `package.json` `dependencies` must stay `{}` - `test/exports.test.ts` pins this.
- **Pure ASCII in every file you write.** Three standing exceptions you must not touch or widen: `src/text/excerpt.ts` (57 non-ASCII bytes), `test/text/excerpt.test.ts` (45), `test/text/extract.test.ts` (3). Zero NUL bytes anywhere.

Fourteen verification instruments have silently failed on this project, including a grep-for-absence satisfied by the comment documenting the absence, a check run against a stale `dist/`, and a positive control that could not fire because the word it searched for was not in the file.

### Task 4: Content-type PDF re-route

**Files:**
- Modify: `src/fetch/read-source.ts` (after `computeSignals`), `src/fetch/pdf.ts` (use the existing `contentType` parameter)
- Test: `test/fetch/read-source.test.ts`

**Interfaces:**
- Consumes: `isPdf(url: string, contentType?: string): boolean` - `src/fetch/pdf.ts:24-27` already accepts the second argument and nothing calls it with one.
- Produces: nothing new.

A PDF served from a URL with no `.pdf` is picked as an HTML rung, N5 vetoes the bytes as not-text, and the document reads `unreachable`. **The constraint:** the pick-before-fetch invariant must hold - do NOT fall through to curl on a failed PDF fetch. What is permitted is a `pdftotext` attempt when an HTML rung returns `application/pdf`, which cannot libel HTML as a PDF because the host said so.

- [ ] **Step 1: Write the failing test**

```ts
it("re-routes to the PDF rung when an HTML rung returns application/pdf", async () => {
  const pdfBytes = readFileSync("fixtures/documents/sample.pdf");
  const fetcher: Fetcher = {
    rungs: ["node", "curl", "pdftotext"],
    async fetch(_url, rung) {
      if (rung === "pdftotext") return { rawBody: "The quick brown fox jumps over the lazy dog.", headers: {}, finalUrl: _url, status: 200 };
      return { rawBody: pdfBytes.toString("binary"), headers: { "content-type": "application/pdf" }, finalUrl: _url, status: 200 };
    },
  };
  const out = await readSource("https://example.com/doc", ["quick brown fox jumps"], { fetcher });
  expect(out.attempted).toContain("pdftotext");
});
```

If `fixtures/documents/sample.pdf` does not exist, use any byte string containing a NUL so N5 fires; the point is a body that is not text arriving with a PDF content-type.

- [ ] **Step 2: Run it and watch it fail**

Run: `npx vitest run test/fetch/read-source.test.ts`
Expected: FAIL - `attempted` is `["node","curl"]`, no `pdftotext`.

- [ ] **Step 3: Re-route inside the loop**

After `reads.push(...)` and before `history.push(...)`, add:

```ts
    // A PDF served from a URL with no .pdf extension. The rung was picked from
    // URL shape before any fetch, so N5 vetoes these bytes as not-text and the
    // document reads `unreachable`. The HOST has now told us what it is, so
    // one pdftotext attempt is licensed - the direction that cannot libel HTML
    // as a PDF. The pick-before-fetch invariant still forbids falling through
    // to curl on a FAILED PDF fetch; this is the other direction.
    if (
      !pdfUrl &&
      isPdf(url, response.headers["content-type"]) &&
      opts.fetcher.rungs.includes("pdftotext") &&
      !attempted.includes("pdftotext")
    ) {
      const pdfRead = await opts.fetcher.fetch(url, "pdftotext");
      attempted.push("pdftotext");
      const pdfComputed = computeSignals({
        rawBody: pdfRead.rawBody,
        headers: pdfRead.headers,
        finalUrl: pdfRead.finalUrl || url,
        status: pdfRead.status,
        claims,
        sourceLabel: opts.sourceLabel ?? "",
        ...(opts.rules ? { rules: opts.rules } : {}),
      });
      reads.push({ rung: "pdftotext", computed: pdfComputed });
      history.push({ rung: "pdftotext", readable: isReadable(pdfComputed.signals) });
      break;
    }
```

Import `isPdf` with its second argument in mind; it is already imported in this file.

Expected: pass. **Watch for corpus movement** - a fixture whose headers carry a PDF content-type would now take a new path. If any verdict moves, report it before continuing.

export async function continueReading(
  url: string,
  claims: readonly string[],
  opts: ReadSourceOptions,
