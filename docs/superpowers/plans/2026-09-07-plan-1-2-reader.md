## Why this plan exists

Fable's review of the plan 2 (`harvest`) design (`.superpowers/sdd/2026-09-07-plan-2-harvest/fable-design-review.md`, F1-F3 blocking) found that the code at 3974d27 answers "did we read this document?" three different ways, and that no test pins any of them:

1. **Two ladder loops with different escalation predicates.** `src/check.ts:109-116` climbs when `challengeHeader || challengePath || challengeSignature`; `src/reachability.ts:80-88` climbs when `isBlocked(signals)`, all five vetoes. A first rung answering 404 with a full page of navigation chrome (N4), or a PDF served as bytes over a text content-type (N5), ends the gate's ladder and not the preflight's. Measured before this plan was written, with a stub fetcher serving 6,740 characters of prose at 404 on `node` and at 200 on `curl`: `check` attempts `["node"]` and returns `unreachable`; `reachability` attempts `["node", "curl"]`.
2. **`!isBlocked` is not "readable".** 22 of the 25 challenge fixtures pass every veto and fail only the prose floor (`docs/calibration-2026-09.md`, "Read together"); so does every paywall stub. The plan 2 design proposed harvesting from `!isBlocked` reads, which would have harvested claims out of walls.
3. **`foldWithMap` desyncs on a lengthening fold.** `src/text/excerpt.ts:95-96` pushes one map entry per INPUT code unit; U+0130 lowercases to two units (`String.fromCharCode(0x130).toLowerCase().length === 2`), so `folded.length === map.length + 1` and every offset after it is one late. Harvest's self-validation cannot catch an off-by-one slice that the source still contains.

Plus the soft hyphen, disclosed in plan 1.1 as a false-miss route and parked. Spec 6.6 now states the rules; this plan implements them with the pins written first.

## Decisions the plan takes as given

From spec 6.6 and the rulings recorded with the user before the amendment:

- **The floor stays 4,500** (`THRESHOLDS.minProseChars`). Not re-swept here.
- **Escalation is unified on "climb unless the last read is readable"** - the wider of the two existing rules. Reach strictly increases; the cost is one extra fetch against genuinely gone documents.
- **Rule 3's `unreachable` arrives through `verdict()` on the largest read**, exactly the 3974d27 route, so the only shape it inherits is the sub-floor union: a full match assembled across non-vetoed sub-floor reads is `supported` when the largest read is not itself vetoed. Task 4 pins that shape; Task 7 adds one sentence to the spec saying so. Rewriting rule 3 to decide from the union alone would move a verdict the spec did not license.
- **`Attempt` carries `readable` only.** The ladder cannot be told a body was "challenged" by one caller's definition and clean by another's.
- **Ties in "most prose" go to the earlier rung** (`>`, not `>=`), as `check`'s reducer already does at 3974d27.
- **`reachability`'s diagnosis of an unreadable URL is unchanged.** Rule 5 changes who is readable, not the reason ladder (gone, then not-text, then challenged, then the prose count).

```ts
import { computeSignals, type SignalResult } from "../classify/signals.js";
import { isReadable } from "../classify/verdict.js";
import { nextAction, type Attempt } from "./ladder.js";
import { isPdf } from "./pdf.js";
import { EMPTY_RESPONSE, type Fetcher, type RawResponse, type RungId } from "./types.js";
import type { RuleSet } from "../rules/load.js";

/** One rung's read of one URL: the rung, carried WITH the classification.
 *  Never read the rung off the end of the attempt history - an earlier rung is
 *  often the one that read the document. */
export interface Read {
  readonly rung: RungId;
  readonly computed: SignalResult;
}

export interface ReadSourceOptions {
  readonly fetcher: Fetcher;
  /** Passed through to the classifier for C1 (slug/label overlap). Absent and
   *  "" are the same thing to it. */
  readonly sourceLabel?: string;
  readonly rules?: RuleSet;
}

export interface SourceReads {
  /** Every rung's read, in the order attempted. Vetoed reads are kept: the
   *  caller decides what a wall's text may and may not contribute. */
  readonly reads: Read[];
  readonly attempted: RungId[];
  readonly pdfUrl: boolean;
}

/**
 * THE ONE LADDER LOOP (spec 6.6). Fetch a rung, classify, climb unless that
 * read was readable, until the ladder stops. Until plan 1.2 check() and
 * reachability() each carried a copy of this loop, and the copies escalated
 * on different predicates - three vetoes in one, five in the other - so the
 * preflight climbed past a 404 that ended the gate's ladder. No test noticed.
 *
 * This module is deliberately NOT exported from src/index.ts (spec 5.3). It
 * returns raw reads, and a caller holding raw reads can assemble a verdict
 * check() never issued. The public surface stays check() and reachability().
 */
export async function readSource(url: string, claims: string[], opts: ReadSourceOptions): Promise<SourceReads> {
  const pdfUrl = isPdf(url);
  const history: Attempt[] = [];
  const attempted: RungId[] = [];
  const reads: Read[] = [];

  for (;;) {
    const action = nextAction(history, opts.fetcher.rungs, pdfUrl);
    if (action.kind === "stop") break;

    // A Fetcher must not throw - see the contract on the interface. The three
    // bundled rungs all return EMPTY_RESPONSE on failure. A third-party
    // fetcher that throws anyway degrades to an unread rung rather than
    // aborting a run midway through a document, and is WARNED about rather
    // than swallowed (ruling C12).
    let response: RawResponse;
    try {
      response = await opts.fetcher.fetch(url, action.rung);
    } catch (e) {
      console.warn(
        `warn fetcher rung "${action.rung}" threw for ${url}: ${e instanceof Error ? e.message : String(e)}`,
      );
      response = EMPTY_RESPONSE;
    }
    attempted.push(action.rung);
    const computed = computeSignals({
      rawBody: response.rawBody,
      headers: response.headers,
      finalUrl: response.finalUrl || url,
      status: response.status,
      claims,
      sourceLabel: opts.sourceLabel ?? "",
      ...(opts.rules ? { rules: opts.rules } : {}),
    });
    reads.push({ rung: action.rung, computed });
    history.push({ rung: action.rung, readable: isReadable(computed.signals) });
  }

  return { reads, attempted, pdfUrl };
}

/**
 * The readable read with the most prose, or undefined when no read is
 * readable. Ties go to the earlier rung. This is spec 6.6 rule 2's "best" and
 * rule 5's "some read is readable", in one place so the gate and the preflight
 * cannot disagree about which read counts.
 */
export function bestReadable(reads: readonly Read[]): Read | undefined {
  let best: Read | undefined;
  for (const r of reads) {
    if (!isReadable(r.computed.signals)) continue;
    if (best === undefined || r.computed.signals.proseChars > best.computed.signals.proseChars) best = r;
  }
  return best;
}
```
